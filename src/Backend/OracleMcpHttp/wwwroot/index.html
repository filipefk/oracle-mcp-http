🔑 Gerador de API Key — Oracle MCP

O servidor MCP recebe um único header, x-api-key, que junta numa só string a sua chave de acesso ao MCP e, opcionalmente, as credenciais do banco Oracle (a connection string). Esta página monta essa string para você — e também faz o caminho inverso.

1. Identifique-seInforme a chave MCP que o administrador do servidor liberou para você.
2. Gere a keyPreencha host, serviço, usuário e senha do Oracle (ou deixe em branco para usar a conexão do servidor).
3. Use no clienteCopie a key e cadastre-a no header x-api-key do Claude Code, Copilot Studio etc.

1 Sua chave MCP

Necessária para usar esta página: o servidor só gera, decodifica ou testa para quem tem uma chave válida.

É uma das chaves cadastradas em McpAuth:ApiKeys no servidor. Não sabe qual é? Peça a quem administra o servidor.

2 O que você quer fazer?

Gere uma key nova, ou cole uma key existente para conferir o que há dentro dela.

É o caso comum. Desmarque só se a key for para outra pessoa, com outra chave MCP.

Onde encontro esses dados?
  • No tnsnames.ora, cada entrada tem HOST, PORT e SERVICE_NAME (ou SID).
  • No SQL Developer / DBeaver, abra as propriedades da conexão já existente: os campos são os mesmos.
  • Conectado no banco, SELECT SYS_CONTEXT('USERENV','SERVICE_NAME') FROM DUAL mostra o Service Name.
  • Em bancos multitenant (12c+), use o Service Name da PDB (ex.: ORCLPDB1), não o da CDB.

Formato do Oracle.ManagedDataAccess. O Data Source aceita EZConnect (//host:porta/servico) ou o descritor completo (DESCRIPTION=...). Nomes do tnsnames.ora só funcionam se o servidor tiver o arquivo.

💡 A key levará só a chave MCP: o servidor usará a connection string da configuração dele (Oracle:ConnectionString ou a variável ORACLE_CONNECTION).

Como usar

          
          

            

            
          

          
Acrescente --scope user depois de add para o MCP ficar disponível em todos os projetos.

          
Em conectores web (Claude Web, Copilot Studio), informe a URL  e o header x-api-key com a key acima.

          

            Como adicionar no Copilot Studio
            
    
              
  1. No agente, abra Tools, clique em Add a tool → New tool → Model Context Protocol.
    2. 
              
  2. Preencha Server name, Server description (diga que o servidor consulta e altera dados num banco Oracle — o agente usa isso para decidir quando chamá-lo) e, em Server URL, .
    3. 
              
  3. Em Authentication, escolha API key, Type = Header e nome do header x-api-key. Clique em Create.
    4. 
              
  4. Na tela Add tool, escolha Create a new connection, cole a key gerada acima e clique em Add to agent.
    5. 
            

          

          

            Como adicionar no Claude Web (conector personalizado)
            
    
              
  1. Planos Free, Pro e Max: vá em Customize → Connectors e clique em Add custom connector.
                  Planos Team e Enterprise: um Owner vai em Organization settings → Connectors → Add → Custom → Web.
    2. 
              
  2. Em MCP server URL, informe .
    3. 
              
  3. Em Authentication, escolha No sign-in.
    4. 
              
  4. Em Request headers, selecione x-api-key, cole a key gerada acima como valor, marque Required e clique em Add.
    5. 
              
  5. Na conversa, ligue o conector pelo botão + → Connectors.
    6. 
            

            
⚠️ O valor do header vale para todos que usam o conector: numa organização, todos acessarão o Oracle com o usuário gravado nessa key.
